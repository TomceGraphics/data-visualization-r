# DataViz-R Documentation

Welcome to the documentation for the data visualization course. This site contains guides on various R functions and data manipulation techniques. Feel free to use it as a reference while working on your assignments or for studying. Also feel free to contribute to this documentation by adding new guides or updating existing ones.

## Data Transformation (dplyr)
These functions are the core "verbs" for transforming and manipulating data frames.

- [Arrange](arrange.md): Reorder data frame rows based on column values.
- [Group By](group_by.md): Group data into subsets for aggregate operations.
- [Mutate](mutate.md): Create new columns or transform existing ones.
- [Rename](rename.md): Change the names of specific columns.

## String Manipulation
Essential tools for searching, replacing, and cleaning text data in R.

- [String Manipulation](string_manipulation.md): A comprehensive guide to `grep`, `sub`, `gsub`, and more.
