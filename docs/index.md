# DataViz-R Documentation

Welcome to the documentation for the data visualization course. This site is a live reference for R functions and data manipulation techniques. 

!!! abstract "Data Transformation (dplyr)"
    The core "verbs" for manipulating data frames. These functions allow you to reshape, filter, and calculate new data efficiently.
    
    *   [**Arrange**](arrange.md): Reorder data frame rows.
    *   [**Group By**](group_by.md): Group data for aggregate operations.
    *   [**Mutate**](mutate.md): Create or transform columns.
    *   [**Rename**](rename.md): Rename columns easily.

!!! info "String Manipulation"
    Essential tools for searching, replacing, and cleaning text data in R. 
    
    *   [**String Manipulation Guide**](string_manipulation.md): A comprehensive look at `grep`, `sub`, `gsub`, and more.
